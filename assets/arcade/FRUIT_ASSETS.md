# Fruit Slice assets / COLLAB-ARCADE-11

Generated with built-in image generation on 2026-10-01 for this game. No third-party game artwork was copied. Both PNGs must ship with the public directory.

- fruit-background.png: Vietnamese tropical night market, teal sky, red/gold lanterns, fruit stalls on the edges, open center, three empty wicker baskets across bottom. No text or UI. Original output 1536x1024.
- fruit-sprites.png: 3x2 atlas; dragon fruit, rambutan, mangosteen / watermelon, durian, rotten fruit. Prompt requested transparent background and an additional background-removal edit, but the returned artwork retained a colored background. Renderer uses oval interior texture masks instead of claiming clean alpha. Cutting effect separates the two texture halves with particles and a slash.

Prompts specified premium colorful 3D-cartoon game artwork, equal cell sizes, no labels/logos, front three-quarter fruit view. Assets are illustrative textures, not geometry. The background is mapped to the responsive playfield; on portrait screens its proportions differ from the landscape version.
