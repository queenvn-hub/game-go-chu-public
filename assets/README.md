# Arcade 3D assets

Generated for this redesign with the image generation tool. These are prerendered PNG images, not editable 3D mesh/rig files.

- `arcade-3d-atlas.png`: three equal square cells, left to right: white/teal spaceship, blue ice crystal meteor, friendly green explorer dinosaur. Canvas crops cells; CSS uses 300% background size.
- `dino-island-3d.png`: colorful floating mountain with a winding path and summit flag, used as the Dino scene backdrop.
- `space-nebula-v1.png`: clean navy/purple galaxy background for the main game, without letters, ship or meteors baked into it.
- `space-sprites-v2.png`: two equal square cells on an opaque black matte, silver/cyan nose-up ship then a dark rocky meteor with a thin orange rim. Canvas uses screen compositing for the matte and a dark disk behind the meteor. This is not a transparent PNG or a mesh.

Art direction: polished, rounded, child-friendly 3D game art; teal/cyan with warm gold accents, soft studio light, readable silhouettes, no text in imagery.

Typography, game targets, answers, counters, and progress are real Canvas/HTML content. Changing lesson text does not require regenerating art.
